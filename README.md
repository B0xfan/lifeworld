# LifeWorld

An Obsidian plugin for projects, tasks and planning. In development, not yet released.

The code here is the Projects part (currently named "A4 Projects" in its manifest).

Source lives in `src/`; `npm run build` bundles it with esbuild into `main.js` at the repo root (not committed).

Tests: `npm test` (builds, then runs every `tests/test-*.js`). They run on every push and pull request.
